# 📖 Sobre o Projeto

O **RPG Nexus** é uma aplicação mobile criada para centralizar ferramentas essenciais de RPG de mesa em um único ambiente moderno, intuitivo e escalável.

A proposta do sistema é oferecer uma experiência prática tanto para jogadores quanto para mestres, permitindo gerenciar personagens, campanhas e informações importantes diretamente pelo celular.

O projeto foi desenvolvido utilizando:

- ⚛️ React Native
- 🔥 Firebase
- 📘 TypeScript
- 🧭 React Navigation
- ☁️ Firestore

# 📱 Objetivo

O RPG Nexus busca transformar a experiência de RPG de mesa em algo mais moderno, acessível e conectado.

A ideia é permitir que grupos organizem campanhas completas sem depender de papel, planilhas ou múltiplas ferramentas externas.
